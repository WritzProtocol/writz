## System Architecture

End-to-end view of how Bitcoin, the relayer, the Writz v1 contracts (`bitcoin-spv`, `writz-lend`) and the browser interact.

![Writz System Architecture](/diagrams/output/01-system-architecture.png)

**Key layers:**
- **Bitcoin** - P2WSH locks collateral; two spending paths (cooperative co-sign or CLTV timelock)
- **Relayer** - submits Bitcoin headers to `bitcoin-spv`, serves SPV proofs, and co-signs the release PSBT after a full repayment
- **Soroban contracts** - `bitcoin-spv` verifies Bitcoin transactions; `writz-lend` holds plaintext positions, the USDC pool and liquidation, priced by the Reflector oracle
- **Browser** - the Bitcoin wallet signs the key-control proof and the release; the Stellar wallet signs Soroban transactions

## Deposit Flow

Step-by-step path from connecting a Bitcoin wallet to having an active position on Stellar.

![Deposit Flow](/diagrams/output/02-deposit-flow.png)

1. Connect Bitcoin wallet (Xverse) and Stellar wallet (Freighter)
2. Derive unique P2WSH address from protocol key + user key + timelock height
3. Send BTC to that address on-chain
4. Relayer serves the SPV proof (block hash + Merkle path + raw transaction)
5. The Bitcoin wallet signs the key-control message (BIP-137) for this contract, depositor and txid
6. `writz-lend.deposit()` rebuilds the P2WSH, calls `bitcoin-spv.verify_transaction`, checks the timelock window and the signature, consumes the txid and creates the position

## Borrow & Repay Flow

How `writz-lend` handles a borrow or a repayment.

![Borrow and Repay Flow](/diagrams/output/03-borrow-repay-flow.png)

- **Borrow:** only the depositor; interest accrues first; the post-borrow ratio at the Reflector price must stay at or above 150%, within pool liquidity and the 50,000 USDC total cap
- **Repay:** partial or full; a full repayment closes the position and emits `repay_full`

## BTC Release Flow (Path A)

Cooperative co-signed release after full repayment.

![BTC Release Flow](/diagrams/output/04-btc-release-flow.png)

- The relayer's repay watcher reacts to `repay_full`, builds the PSBT and co-signs it with the protocol key
- The half-signed PSBT is published on `writz-lend` (`publish_release_psbt`) and can be read with `get_release_psbt` even if Writz is down
- Final witness: `[user_sig, protocol_sig, 0x01, redeemScript]`
