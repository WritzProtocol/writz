# Writz landing

The marketing site and press page, served at writz.xyz. Next.js (App Router),
React, TypeScript, Tailwind v4. It has no wallet, chain or ZK dependencies:
the dApp lives in `../app`.

## Setup

    cp .env.example .env.local
    bun install
    bun run dev

## Design system

The shared visual language is documented in `../DESIGN_SYSTEM.md`.
