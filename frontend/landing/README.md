# Writz landing

The marketing site, served at writz.xyz. Next.js (App Router), React,
TypeScript, Tailwind v4. No wallet, chain, or ZK dependencies, that code
lives in `../testnet` and `../mainnet`.

## Setup

    cp .env.example .env.local
    bun install
    bun run dev

## Design system

Shared visual language across all three apps is documented in
